# CliniVol Design System V1.0 — Component Rules

| 组件 | 规则 |
|---|---|
| Button | TDesign原交互，14/22 Regular，中等点击区域；Primary沿用品牌Normal/Hover/Active，不强改灰；实心Primary使用对应主题品牌语义及TDesign Anti前景（Dark官方Anti=#FFF）；禁用仍沿用组件禁用色。图标与文字垂直居中，间距8px。 |
| Tag | 状态语义独立：未开始灰、进行中Info蓝、待审核Warning橙、审核退回Error红、已完成Success绿；不能用品牌绿代替进行中。 |
| Tooltip | 只限定`.t-tooltip--default`，Light容器白底/主要文字/shadow-2/8px；Dark对应表面/浅字。箭头为12px同表面图形，和主体重叠衔接，无菱形边框拼缝。 |
| Dropdown/Popover | 保留TDesign机制、完整14/22文案、不裁切；radius-medium8px、shadow-2；不继承Tooltip专用白底覆盖。 |
| Dialog | radius-large12px与shadow-3，标题Medium；保持原关闭/确认/取消及真实权限，不新增假成功。 |
| Table | 全部正文表头14/22 Regular，单行、省略+Tooltip；固定项目编号/医院/名称三列和右操作列，中间横向滚动。首页最多6项目。 |
| Card | 白色或主题表面；首页大卡片/平台通用Card使用tdesign-react 1.18.4官方默认6px（.t-card → --td-radius-medium，官方值6px），不强制8px；无额外常驻描边阴影；设计阶段卡片是既有浅边框例外；宽内容1140起四列、760起两列、否则单列。 |
| GlobalHeader | 固定56px和既有Logo区域，保持现有头像与任务Tabs；四公共操作Icon用主要文字色，Hover灰，无新增分割线/投影。 |
| Sidebar | 原宽度224/64；选中品牌底白字，默认图标主要文字色，Hover灰；底部收起入口保留。 |
| 三维重建工具栏 | 单排58px；AI/视图/图像/分割，分类浅品牌选中，上下文持续工具品牌实底；一次性命令不保持激活。移除文件/插件入口。 |
| CAD工具栏 | 原单排58px纯Icon+Tooltip和下拉分组，现有命令/浮动参数/模型选择/历史不变。 |

## 交互状态

Default沿用默认表面与主要文字；Hover使用对应中性灰Token；Selected/持续Active使用品牌语义；禁用保持准确的Disabled，不执行命令；Focus使用brand-color-focus可见反馈。禁止全局重写所有:hover。列表Hover覆盖完整有效行宽，独立按钮只反馈自身。

## 数据与导航

以A任务/订单ID聚合项目，名称不作主键。首页/完整列表/最近项目/重要通知/Header通知复用新版ProjectDetail；专业工作区仍按任务ID操作。保留A原localStorage键，不读取实验命名空间，不导入E*实验任务，不改写真实审核身份。任务004/005/006/007的状态与上下游关系保留；任务005未解锁不可进入；006成果只读；007绑定唯一已批准模型。

## 医院与原型来源

医院字段来自项目级数据。已知原型订单可使用demoProjectMetadata中两家医院；仅在非production记录中回退到演示映射。真实记录没有医院则显示空值，不用演示映射补造。名称一致不表示真实客户合作。

## AI与统计能力边界

AI十项按用户顺序显示，使用正常图标/文字色并开放处理范围确认；未连接计算服务时如实反馈，不执行假分割。原图像/分割工具及其既有原型操作保留。蒙版体积与统计移至视图，因为没有可计算的体素蒙版而禁用。STL属性统计同属视图：只在当前工程明确关联实际展示STL时读取原文件的三角面、包围盒与文件大小；无文件时禁用，读取失败明确报错，不产生医学结果。

## 不改变的领域

CT黑底、3D医学视图白底、方向识别色与红色审核定位、CAD模型原材质/几何、自动保存/提交/退回/解锁机制均保留。当前浏览器原型不等于真实临床算法、服务端鉴权或制造级CAD内核。

## 2026-11-03主题与阴影确认

Light保持最终Figma色彩及#F5F7F9页面背景例外。Dark仅替换品牌绿阶梯，Normal=Brand8、Hover=Brand7、Active=Brand9；其余全部采用TDesign官方Dark。品牌文字与链接随Brand8；Info独立引用官方原品牌蓝，不能随品牌覆盖变绿。三级阴影均为官方默认参数，不给Header或白色卡片新增投影。精确色值与未来Figma映射见tokens.md和figma-variable-mapping.md。本轮已同步运行CSS/JSON；Figma尚未修改。

## 审核、CAD保存与方案边界（最新修订）

统一称“提交审核”，审核人由未来管理员后台依据具体任务和权限指定，可以是医生、管理员或其他授权人员，不固定为医生。保留现有提交、退回、正式成果锁定及上下游解锁规则，不追改真实历史身份。

CAD真实工程修改后自动保存，不要求手动保存；顶部已保存时间取自实际保存成功记录，保存中/失败状态如实呈现。CAD工具栏不得重新添加独立“保存工程”按钮。

A为唯一正式主方案；B已弃用并历史归档，不进行日常开发、维护或部署，未经专项授权不修改或覆盖。双端审核原型作为独立实验环境保留，可先验证复杂审核功能，与A的代码及部署隔离。

审核入口为单一“提交审核”按钮，无下拉与审核对象选择；对象由后台授权决定。审核意见A区默认全部展开，仍保留独立滚动与单条标题省略/展开。新增demo项目独立持久化，分页每页6条；按状态开放现有工作区，演示展示资源不得冒充该患者真实成果。

## 最新交互修订（本轮优先）

AI十项开放正常颜色的参数确认入口，替代上文统一禁用要求；未连接计算服务不生成虚假结果。演示目录任务独立持久化，按状态开放重建/CAD工作区，不使用ID前缀禁用。CAD仅在明确catalogDemo且dataOrigin=demo时复用本地STL；生产模型资源校验不变。分析/打印缺少文件时只显示资料信息。成果查看不再沿用编辑者或CAD上游解锁禁用条件；编辑仍保留所属人员和上游规则。
