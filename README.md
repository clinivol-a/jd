# CliniVol Web UX Prototype

面向三维重建设计师的桌面端中保真交互原型。平台层使用 TDesign React，专业工作区采用自主布局；所有外围界面为浅色，仅医学影像 Viewport 使用深色背景。

## 本地运行

```bash
pnpm install
pnpm dev
```

浏览器打开终端显示的 Local URL。生产构建：

```bash
pnpm build
```

## 核心验证路径

1. 工作台点击「我的任务」。
2. 打开任务 001 的详情并点击「继续设计」。
3. 在工作区点击「Mask 编辑」或其他工具产生未保存修改。
4. 点击「保存」，确认保存反馈。
5. 再次修改并点击「提交医生审核」。
6. 确认提交后，检查工作区只读锁定状态。
7. 返回工作台，检查任务 001 状态更新为「待审核」。

顶部 `+` 可打开其他已有任务；任务 002 用于验证审核退回，任务 003 用于验证待审核成果锁定。

## 组件边界

- TDesign：Dashboard 卡片、任务与订单表格、业务导航、按钮、标签、输入框、通知抽屉、账户下拉、对话框与消息反馈。
- 自主实现：固定 GlobalHeader 的内部任务标签、专业软件菜单、View / Segment / Model / Measure 工作区、上下文工具栏、Series 树、四视图、对象与属性面板。

## 说明

- 所有患者、订单与审核信息均为模拟数据。
- 原型不解析 DICOM，也不执行真实分割、重建或医学计算。
- 四视图中的灰阶图形、交叉线、模型、测量数据与性能信息均为演示效果。
- 浏览器状态使用 `localStorage` 保存；如需恢复初始数据，可清除当前站点的本地存储。
