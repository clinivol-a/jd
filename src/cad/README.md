# CAD 工作区 · 第一阶段

本模块仅供方案 A 的本地交互验证，复用 App 的任务入口、任务标签与提交审核流程。

## 资源与来源

- `public/assets/cad/HumanSkull_Jaw.stl` 来自用户提供的 `STL_human_skull_3demon.zip`，未覆盖下载目录中的原始 ZIP / OBJ。
- 此资源是任务 007 的显式展示映射，不是任务 006 经过医生审核产生的文件证据。业务关联仍指向任务数据中的上游模型 ID 与 V05。
- 原始 STL 为无单位坐标，查看器按 mm 解释；204,768 个三角面、闭合网格；检查未发现非有限坐标、退化面、边界边或非流形边。
- 原始轴向范围约为 101.396 × 89.121 × 64.494，表面积约 17,070.08，闭合网格体积约 52,357.24（按上述单位解释）。
- 浏览器中只进行轴向转换、居中、合并重合顶点及重算法线，不修改静态源文件。会话内缓存解析结果，工具操作不会重新请求 STL。
- 修复板、螺钉、导向模板由几何体搭建，属于初始化示意对象。特征历史从空列表开始，只记录用户确认的操作。

## 能力边界

- 真实功能：WebGL 模型加载、射线选择、轨道旋转/平移/缩放、方向控制、视觉剖切、几何包围盒/表面积/网格体积计算，以及树、视窗、属性联动。
- 示意建模：草图图元、闭合轮廓拉伸、修复板贯穿孔口、端部圆角和对象平移。孔深参数记录在特征中，网格孔口按贯穿处理。尺寸与约束只记录标注，不具备约束求解器。
- 草图在 XY（z = 45）、XZ（y = 0）、YZ（x = 0）平面上拾取与显示；拉伸采用所选草图中的首个矩形或圆轮廓。预览与确认结果共用平面变换，正向分别沿 +Z、−Y、+X，反向取反；不支持任意曲线闭合、轮廓组合或拓扑校验。
- 工具配置集中在 `cadToolCatalog.ts`：基础建模、结构与实体特征、复制与变换、参考几何、曲面、查看与辅助。旋转体（Revolve）与变换中的对象旋转使用独立 ID；未接入的命令禁用，不映射到其他命令。材质为示例选择，制造参数未校核。
- 不具备 B-rep / 精确实体内核、制造与临床校核、真实云端保存、身份认证或跨账号医生通知。

## 工程与审核

- 浏览器 `localStorage` 中，`clinivol-cad-project-<taskId>` 保存当前工程；`clinivol-cad-snapshots-<taskId>` 保存提交审核的独立快照。数据仅在当前浏览器站点存储中，没有跨浏览器或账号的同步服务。
- 真实工程内容变化后防抖 1000ms 自动保存；草图须“完成草图”、特征须确认后才进入工程。未确认的预览、对象选择、面板切换、视角旋转及缩放不触发保存。Ctrl/Cmd+S 可立即保存或在失败后重试；内容未变化时保存时间保持不变。
- 工程和上游的内部版本标识、提交快照仍保留用于审核追溯，工程师界面不展示显式版本号或版本历史入口，自动保存不递增版本。
- 保存异常保留失败状态，不显示“已保存”，也不允许提交。审核中或已完成任务保持只读。
- CAD 的提交、只读状态、审核评论面板和流转事件使用方案 A 现有处理机制。医生端和跨账号流转依赖已有审核服务接入，本模块不建立第二套审核系统。

## 视觉与布局

- 完整复用 GlobalHeader。单行 CAD 工具栏与三维重建共用 58px 高度变量，左模型树、中间 3D 视窗、右上下文属性、32px 共用状态栏。
- 常规文本 14px / 22px，品牌绿色与主题面板 Token 沿用现有方案 A；CAD 视窗浅色为 #FFFFFF、深色为 #24292D，WebGL 清屏色实时跟随主题，模型材质和灯光保持不变。
- 建模命令的参数、确认与取消统一放在视窗左上浮动面板；右侧仅保留对象属性；测量、分析和截面同样使用视窗内浮层。模型采用均匀基础光照，不使用地面或投射阴影。
- 窄桌面把低频工具收进“更多工具”；树与属性内部滚动。审核意见开启后沿用既有评论布局。
- CAD 默认与草图工具栏均为纯 Icon + Tooltip；圆角、阵列、变换、参考几何、曲面及分析支持下拉分组，参数面板与已有命令处理器保持独立。工具的可用性、只读权限和溢出菜单使用同一配置。

### CAD 命令与侧栏交互一致性（2026-10-29）

- 所有已启用命令（草图、拉伸、孔、圆角、移动、测量、截面、几何/网格信息）均使用视窗内同一浮动面板。固定右侧栏仅展示对象属性。
- 拉伸缺少闭合轮廓时，字段内可进入草图；完成后恢复拉伸参数并选择新草图，取消则返回原拉伸而不创建特征。无有效轮廓时不绘制拉伸预览。
- 截面支持 X/Y/Z 法向、偏移、方向和重置；退出后清除裁剪，不持久化或修改模型几何。测量/分析读取网格结果，不要求确认。
- `useCadPanels.ts` 仅管理 UI 偏好。侧栏宽度为左 184–480px、右 252–480px，并受可用视窗宽度限制；拖拽至 80px 以下收起，边缘按钮恢复拖拽前宽度。支持键盘方向键调宽、Home 收起。
- 拖拽使用 Pointer Capture，调整时屏蔽视窗拾取/旋转。容器变化由现有 Three.js ResizeObserver 响应，工程保存数据不包含侧栏宽度。
- 命令激活、选中对象、相机及侧栏操作不触发工程保存。提交入口保持挂载和既有业务禁用条件，CAD 提交按钮固定原生 button 标签（避免 TDesign 默认在 disabled 时改用 div）；未完成命令由提交处理器阻止；工程内容修改后仍按 1000ms 防抖保存。
- 手动收起属性栏后，普通选择不强制重开；命令中的几何选择也不会打开属性栏。主动展开可查看当前对象。
- 未实现的高级命令继续禁用，不展示开发阶段文字，不生成假运算结果。TDesign 眼睛/锁图标由 `ObjectStateIcon` 与三维重建对象列表共用；普通可操作按钮在 Hover/Focus 显示，隐藏/锁定标识保留。

## CAD 视图与编辑补充（2026-10-29）

- 已确认工程编辑进入最多50步的撤销/重做历史；连续名称、颜色和透明度输入合并为一步，显隐、锁定等离散动作独立记录。切换同一页面内的任务标签可恢复工程历史；刷新页面不恢复撤销栈。审核只读或已提交状态清空/禁用编辑历史，不涉及业务事件。
- 工程历史包括草图、拉伸、孔、圆角、对象平移、旋转、缩放、镜像、重命名、删除及允许编辑的属性。工程撤销会触发原有1000ms自动保存；临时预览不进入历史。删除设计对象一并移除其关联特征记录，撤销可恢复。
- 参考模型的颜色、透明度、显隐，以及临时隔离、恢复显示、参考平面显隐，保存为独立 `clinivol-cad-view-<taskId>` 显示偏好；不修改批准的工程数据或原始STL，不影响工程保存时间。设计对象常规外观编辑仍进入工程和撤销历史。
- 模型树和中央画布共用一个按类型分流的上下文菜单；参考网格无删除或几何编辑入口。右键射线选中与模型树、对象属性联动；空白处提供视图命令。菜单支持边界避让、内部滚动、方向键和Escape。活动命令中不打开新菜单，右键拖动与右键单击按5px阈值区分。
- View Cube六面随真实相机方向旋转。下拉菜单提供前/后/左/右/俯/仰、等轴测、适配、上一个视图、正交/透视切换、边线和默认方向。适配按当前可见对象计算，不改变几何或材质，不增加地面阴影。
- 参考几何分组显示当前实际存在的XY/XZ/YZ草图参考平面（沿用既有草图坐标，XY位于Z=45mm），可分别查看和显隐；这不等于支持任意新建参考几何命令。搜索同时覆盖模型、草图和特征名称。
- 本轮新增可操作的对象旋转、统一缩放和沿坐标法向镜像，提供预览、确认/取消和特征历史；这些是独立设计对象的变换，不是Revolve旋转体或B-rep实体内核操作。已补齐移动面/删除面/替换面菜单定义，仍禁用。

### 快捷键

- Command/Ctrl+Z：工程撤销；有未确认建模命令时先取消预览。
- Command/Ctrl+Shift+Z、Ctrl+Y：工程重做。
- Escape：先关闭上下文菜单，否则取消当前命令。
- Delete：删除允许编辑的设计对象；上游参考、锁定对象、只读任务不执行。
- F：适配当前选中对象，无选中对象时适配可见模型。
- Command/Ctrl+S：复用原工程保存与失败重试逻辑。
- 输入框、文本域及可编辑文本中不截获工程快捷键；非活跃CAD标签不执行这些命令。

### 当前未启用的高级命令（29项）

- 基础建模：旋转体（Revolve）、扫掠、放样。
- 结构特征：面混合、倒角、抽壳、拔模、加厚、加强筋。
- 几何操作：线性阵列、圆周阵列、曲线阵列、布尔、分割、移动面、删除面、替换面。
- 参考几何：新建平面、轴、基准点、螺旋线、3D拟合样条、投影曲线、复合曲线、交线。
- 曲面：偏移曲面、边界曲面、填充、直纹曲面。

上述工具保持标准Disabled，不映射到无关命令，不生成假的几何计算结果。`node scripts/check-cad-history.mjs` 可执行工程历史、变换、存储失败、手势阈值及相机历史的局部检查。
