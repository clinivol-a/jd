# 首页三条摘要与设计师列表间距定向修正

## 三项结果

1. **设计师列表**：我的项目和审核记录使用同一标题容器及销售列表既有节奏。修正视角切换容器额外的上下Padding，保持按钮原字号和32px高度；审核表头与数据行采用现有项目表格密度。未改筛选字段、业务数据和权限。现有动态分页机制保持不变，按各页筛选实际占高计算容量，不硬凑相同条数。
2. **销售首页**：我的待办与我的业务范围各恢复最多3条；近期订单仍保持既有7条。完整待办和客户列表保留全部数据及动态分页。我的业务范围“查看全部”复用客户管理列表，通过来源路由显示“返回工作台”；从Sidebar直接进入客户管理时不多加返回按钮。
3. **设计师首页**：最近项目与重要通知各最多3条，两个Card均有“查看全部”。完整最近项目沿用既有最近操作时间排序及Project ID跳转；完整通知复用同一通知数组、已读状态及原项目跳转逻辑，提供既有全部/未读/已读筛选。没有生成或删除记录。两个完整列表均复用TDesign Table、动态分页及PageBack。
