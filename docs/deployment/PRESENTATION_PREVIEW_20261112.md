## 实现
- 前端仍为确认后的 React/Vite 项目，只通过 VITE_PRESENTATION_DEMO=1 在隔离汇报构建启用现有演示验证码面板。

- 入口要求随机邀请凭证。仅合成陈屿/李明账号；认证状态以 AES-256-GCM 加密、HttpOnly/Secure/SameSite Cookie 保存，8小时会话。每个浏览器独立，不共享评审人的注册和审批操作。
- 原本地认证文件保持生产禁用规则。准备脚本只对私有发布包中的适配器副本设置 Preview 限制；Function 在非 Preview 环境返回404。
- 密钥、邀请凭证、合成账号哈希仅放在 .local 私有 Function 包，不进 Git 或静态资源。
