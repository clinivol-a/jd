## 使用方式

分别运行 `pnpm auth:dev` 与 `pnpm dev`，打开 http://127.0.0.1:5210/#auth/sms 。复用 5210/5211 端口。

- 陈屿：13800000001，已审核的三维重建设计师。获取验证码后打开右下角“演示数据”，读取该手机号/用途的真实后端验证码，勾选协议后登录，进入原 A 首页。
- 李明：13800000002，初始尚未注册。从“注册新账号”验证手机，密码可暂不设置，填写李明与单位，申请“销售”，提交后显示审核中。在控制台选择审核中/通过/未通过，服务端真实更改申请状态；通过后点击进入工作台，只进入销售界面。
- 先登录陈屿，再通过账户菜单“添加账号”注册李明，可以保留陈屿的有效会话。在李明菜单中可切回陈屿，恢复重建/CAD任务标签。
- “重置账号测试数据”需要确认。只清理隔离认证服务里的其他测试账号、验证码、扫码及相关会话，保留陈屿账号；不触及 A 方案的项目、工程、任务、本地工作区或主题数据。

## 安全边界

控制台由 `import.meta.env.DEV` 条件懒加载。Production JS 不包含控制台组件或 `dev/state`、`dev/review`、`dev/reset` 调用。

后端必须同时满足 local 模式、明确启用 `AUTH_DEV_CONSOLE=1`、未配置公开 Origin、非 production 运行环境。Vite 的本机开发代理读取 0600 私有随机能力密钥并注入请求头；密钥不发给浏览器，来源/请求校验仍然保留。缺少有效代理能力、外部 Origin 或公开代理头的请求均被拒绝。公共测试/生产默认不开启这些路由，不是仅用 CSS 隐藏。

验证码来自 `AuthService.sendCode`，仅当前浏览器设备可查看自己的测试收件箱。最多显示最近十项手机/用途组合，服务端控制五分钟过期、60秒重发、错误次数及一次性校验；已用/过期代码不再返回可复制数字。控制台不返回密码、哈希、盐、微信身份或认证密钥。

测试审批只处理有注册申请的销售账号，审批通过授予 `sales:landing`，不能从控制台给陈屿重新改角色或给李明授予工程师权限。此审批是隔离本地测试行为，不代表接入生产管理员审批服务。
