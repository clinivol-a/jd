# 十四项功能权限

按用户确认顺序：订单管理、订单审核、任务分配、账号注册审核、医生档案审核、权限申请审核、组织管理、医院管理、岗位管理、成员管理、专业成果查看、成果分享管理、导出资产信息、审计日志。

组织管理 organizations:manage、医院管理 hospitals:manage、岗位管理 roles:manage、成员管理 people:manage 分别执行服务端校验，前端 Tab 和操作同步检查；成员配置由成员管理授权，权限申请审核维持 permissions:grant。新初始化和完整保存的管理员使用同一十四项目录。旧完整管理员的既有机构管理能力只读兼容，不改写既有授权与审计；旧不完整成员管理授权不被推导为其他三项权限。

业务组长可配置的业务权限及区域规则保持，普通员工不获得管理权限，管理员十四项全部开启且不能单项撤销；专业权限未变。浏览器核对赵启明十四项名称、顺序、开启与禁用状态，结果见 browser-labels.json 和 permissions.jpg；未保存成员变更。

TypeScript、Vite 构建通过，保留既有大包提示。受影响现有测试与新增权限隔离测试共 112 项通过。两个旧订单测试夹具由人员管理授权改为医院管理授权；原“仅有权限申请审核的管理员不能改成员”检查改用独立审核权限，保留拒绝越权的断言。git diff --check 通过。
