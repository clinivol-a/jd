## 实际结果

1. 分组间32px，标题到本组内容12px；功能权限首行移除额外12px顶部Padding。浏览器逐组实测均为32/12，见[测量结果](measurements.json)。
2. 管理范围只显示负责区域；移除现有生效范围及其医院名单。普通员工没有区域配置项时，不显示空的管理范围分组。底层医院关联、权限与成员表的生效范围列保持原样。
3. 注册上一轮已有“无专业岗位”选项，本轮没有修改注册。服务端仅允许内部组织成员以该选项提交，仍需审核；审核通过不会自动获得管理角色，未授权时停留等待权限配置。赵启明、许文清仍是预置管理登记，没有伪造其已注册的历史。正式首个管理员的受控初始化仍是上线接入边界，不能解释为系统随机派发管理权限。
