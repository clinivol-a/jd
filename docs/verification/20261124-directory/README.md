新医生只保存草稿或提交待审核，正式销售归属在审核批准时核准。销售代填实际归档文件后提交；邀请已验证提交按稳定lead ID幂等进入待审核目录，保留实际提交人及邀请来源。伪造客户端invite来源、文件类别、越权医院及医生选择均不能直接通过服务端校验。
