# 管理员 Tooltip 定位与权限含义

2026-11-27，仅本地修改；未部署、未调整权限或业务数据。

## 修正

AdminTable 已提供官方 ellipsis Tooltip，FullText 原先额外包裹常驻 Tooltip，且 span 为整列宽度。因此未截断的短文字也显示提示，箭头围绕整列空白中心定位。移除内层 Tooltip 及整列宽度样式，由 Table 判断实际溢出；操作列不再套省略 Tooltip。表格浮层挂载 body，避免表格容器裁切。

成员开关 Tooltip 的触发包装统一 inline-flex，定位在控件左侧；任务操作区提示 top-right。沿用当前箭头、表面、阴影和 TDesign 自动翻转机制，没有全局位移补丁。

前三项权限补充说明：订单管理查看授权范围内的订单列表、详情、任务进度；订单审核由当前负责组长受理或退回待审核订单；任务分配由当前负责组长为已受理订单中尚未开始的任务配置负责人及计划时间。后台条件保持不变。
