3. 医生资质两份文件已在共享目录服务端持久化；订单附件沿用既有browser存储机制。本轮未改造成生产对象存储，不宣称跨设备文件分发已实现。
4. 未重跑11-24已通过的76项测试和TypeScript/Vite构建，因为应用代码没有变化。本轮新增的是实际浏览器验收。
