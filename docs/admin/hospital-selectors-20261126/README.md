# 医院人员选择器与组长区域分工（2026-11-26）

基线：273be8a。安全分支：codex/backup-hospital-selectors-20261126-273be8a。

## 原因与修复

1. 原新建医院在未选择区域时给出空的负责组长列表。现明确显示“请先选择区域”，选择后只列出合资格人员；无合资格人员说明需在成员管理维护授权。必填与资格失效错误在对应字段下显示。
2. 依用户本轮确认，ADM-L01赵启明负责合肥；ADM-L02现有姓名为许文清，负责合肥以外15个安徽城市。统一新建/编辑医院、订单变更组长、服务端保存及本地组长权限适配的候选条件。明确区域授权优先，不能以旧医院绑定绕过。
3. 原地区规则只在部分入口支持“安徽”覆盖城市；现复用相同匹配，并兼容城市名称的“市”后缀。
4. 当前赵启明缺少orders:read；按明确的组长职责补齐订单查看/审核/任务分配最小权限。一次性迁移记录完整before/after，之后再次重启不会恢复被人工撤销的权限。
5. 授权销售原先要求已有salesAssignments条目，导致新通过账号被排除；直接读取服务端实际启用销售候选ID，不因无旧医院授权排除，也不把过期演示人员映射作为可选账号。
6. 已有医院主数据的负责组长按上述区域更新；订单历史负责人、订单/项目/任务/事件不批量重写。完整数据备份位于忽略目录.local/backups/before-leader-regions-20261126-111050。共享业务state.json重启前后SHA256完全一致。
