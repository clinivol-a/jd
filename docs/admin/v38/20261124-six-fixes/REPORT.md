## 六项结果

| 问题 | 修复及实际检查 |
| --- | --- |
| 首页订单字段缺少 | 首页直接复用二级订单列表的 `orderColumns`，同一配置、同一顺序：订单编号、手术项目名称、医院、科室、医生、患者、设计阶段、订单状态、负责组长、最近更新时间、创建时间、预计交付时间、操作。浏览器已打开首页及二级列表核对；首页原摘要数量与日期规则不变。 |
| 概览标题与 More | 改用已有 `project-page-heading` 标题结构；删除详情标题右侧 More，列表原有 More 保留。 |
| 字段间距 | 恢复详情页面容器和已有信息网格，清除设计需求最后段落的额外底部 Margin，保留需求自动换行。 |
| 附件不可预览 | 取消统一禁用。增加受现有登录、管理角色、订单范围和文件归属校验约束的预览读取。实际点击打开 NIfTI、PDF、PNG；未增加下载按钮。 |
| 设计阶段不同 | 沿用销售已有三行卡片结构：编号名称与状态、负责人、进展与操作；不再把标题做成另一套阶段 Tag。四阶段订单已在浏览器核对。 |
| 操作记录粘连及三行 | 保持独立兄弟 Card，卡片间距20px；事件名称与阶段在第一行，时间、操作人及已有意见在第二行。CV-2026-0001 的阶段事件及退回意见已实际查看。 |
