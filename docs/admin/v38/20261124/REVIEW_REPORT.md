## 实际业务路径

所有写操作均发生在 `.local/admin-qa-20261124` 的私有数据副本。没有向原业务库写入测试审核、权限或任务事件。最后已切换为从原数据重新复制的本地预览副本 `.local/admin-preview-20261124`，不把验收新增的两条医生用例混入最终预览。

### A/B：订单审核、销售重新提交、任务分配

使用已有待审核订单 `CV-2026-0017`，不是额外伪造一笔新业务：

1. 管理员筛选并进入同一订单，接管必填原因校验通过后保存。
2. 管理员退回，李明重新登录后读取到相同编号及具体原因。
3. 李明修改隔离副本中的设计需求，通过原四步订单流程重新提交。
4. 管理员读取相同订单的更新需求并受理，约定交付日期为 `2026-12-21`。
5. 仅建立一个主项目，独立分配三维重建与 CAD 任务给具备资格的陈屿。
6. 陈屿完整工作台读取到该项目；两个独立任务沿用同一业务编号；CAD 仍提示等待上游成果审核通过。

### C：医生及账号审核

- 原有合成资质资料的受保护预览可以打开，医生档案停用/恢复均返回真实保存结果。
- 为避免改写原审核历史，在私有 QA 副本添加 `QA-DOCTOR-APPROVE`、`QA-DOCTOR-RETURN` 两个可控用例；分别实际执行通过及退回。退回为空被字段校验阻止，填写的具体原因保存到新历史事件。
- 对隔离人员申请 `ADM-Q02` 执行账号开通审批：无书面依据时阻止；填写依据后审批通过并新增对应隔离人员登记。没有把这一步冒充真实认证账号开通。
- 正式专业成果审核接口仍未接通，保持禁用；没有生成专业审核通过结果。

### D/E：医院、人员、权限

- 医院负责组长从许文清调整为赵启明，新增真实变更事件；已有订单责任人不被连带改写。
- 顾清和隔离人员登记停用后状态保存，随后恢复；真实认证账号启停未开放。
- 对资产查询权限提交申请、通过审批、核实授权、再撤销；审批前不授予，撤销有依据与原因，并保留历史。

### F：资产与日志

- 打开真实成果元数据，读取对应订单、项目、任务、版本及提交事件。
- 未接入的专业预览/审核/分享撤销保持禁用。
- 受控元数据导出实际返回成功，日志新增导出事件；单元测试确认输出字段不含患者身份字段或源文件下载地址。未单独读取浏览器下载落盘文件。
- 审计业务类型筛选后重置为空，恢复完整记录；详情显示变更前后快照。
