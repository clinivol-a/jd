## 服务与权限

新增业务集中 `server/admin/` 与 `src/admin/`。本地认证端口5231，Vite5230；已有5210/5211默认不变。销售与成果插件在新环境复用配置化authOrigin，不修改原业务逻辑；新环境不争用旧LAN网关端口。

`GET /api/admin/state`、`POST /api/admin/command`、`GET /api/admin/preview/:id` 均由服务端已有HttpOnly会话确认当前用户、启用状态及未锁定状态。管理角色+具体权限共同决定操作；非超级管理员另按医院范围约束。跨站请求、伪造body角色、过期记录版本、无效对象/阶段/交期均拒绝。普通销售和工程师无法读取管理快照及资质预览接口。

业务状态在 `.local/admin/state.json` 原子替换保存（0600）。认证数据在独立 `.local/auth`。后端返回源标识 `isolated-admin` / `local-auth`，不与销售/工程师LocalStorage合并。正式后端事务、跨进程并发、灾备及多租户授权仍需生产服务实现；当前版本保护覆盖单进程本地演示，不宣称生产安全认证完成。

合成资料具有稳定ADM命名空间。种子中的审核通过/退回样本标明 `source=isolated-admin`，不写入正式审计系统；审计列表初始不预造管理成功事件。后续点击操作用实际登录人和实际时刻留痕；本地认证记录来自现有AuthService，未改写旧身份。
